- **定義**: 停止条件を満たすまでAIエージェントが「実行→検証→次判断」のサイクルを自律的に繰り返す仕組み。プロンプト→コンテキスト→ハーネス→ループ、という工学の進化系譜の最終段階。

## 導入順序としての読み替え

1. **②でルールと停止条件の基準を決める**(判断原則の文書化・ゴール条件の定量化)
2. **③で基盤を作る**(外部記憶・機械判定・スキル化の3点セット)
3. **⑤でAIにループを回させる**(役割分離した複数エージェントが自律実行)
4. **④の3判断だけ人間がゲートとして残る**(設計レビュー/区切り/リリース判断)
5. **①がそれ全体のコスト・リスク方針を承認し、段階的にスコープを広げる**

記事が繰り返し強調しているのは、「⑤を先に自動化してから②③を後追いで整備する」のは失敗パターンで、**判断基準(②)と検証機構(③)が先、ループの自律実行(⑤)は後**、という順序です。
